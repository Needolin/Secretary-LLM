# Секретарь — расписания и AI-ассистент

Flask-приложение с мультиагентным Orchestrator. GPT-5 Mini через Cloud.ru Foundation Models распознаёт команды пользователя, а специализированные агенты выполняют операции.

## Что есть в этой версии

- Расписания с периодом «День», «Неделя» или «Месяц · 28 дней». Период выбирается при создании и после этого не меняется.
- Закрепление расписаний через контекстное меню правой кнопкой мыши; там же расписание можно удалить.
- Центральный таймлайн и отдельная закреплённая справа панель чата. Список «Недавние чаты» убран; при нескольких диалогах для расписания доступен компактный переключатель.
- Два типа записей в интерфейсе: **Событие** — неоновая линия с выбранным пользователем цветом; **Дедлайн** — яркий крестик с выбранным цветом.
- Создание события и дедлайна из быстрых кнопок над таймлайном.
- Редактирование и удаление существующих записей нажатием на маркер.
- Светлая и тёмная темы, выбранный режим сохраняется в браузере.
- Старые записи `type="task"` сохраняются и показываются как дедлайны; существующие расписания не удаляются.

## Установка

Рекомендуется Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Настройка Cloud.ru

1. Создайте API-ключ с доступом к **Foundation Models**.
2. Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

3. Укажите ключ:

```dotenv
CLOUD_API_KEY=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ
CLOUD_MODEL=openai/gpt-5-mini
SECRETARY_TIMEZONE=Europe/Amsterdam
```

Не публикуйте `.env` и не добавляйте его в Git.

Проверка API:

```powershell
python -m Application.Agents.OrchestratorAgent.check_connection
```

## Запуск

```powershell
python Application/Site/app.py
```

Откройте http://127.0.0.1:5000.

## Управление расписаниями

- Нажмите «Новое расписание» в левой панели. Выберите период сразу при создании.
- Щёлкните правой кнопкой мыши по расписанию, чтобы закрепить/открепить или удалить его.
- Формат расписания после создания фиксирован. Для другого периода создайте отдельное расписание.

## События и дедлайны

- Кнопка «Событие» открывает форму с днём, временем начала/окончания и HTML color picker.
- Кнопка «Дедлайн» открывает форму с датой и своим color picker.
- Нажмите на линию/крестик на таймлайне, чтобы отредактировать цвет, название и доступные параметры или удалить запись.
- Старые записи задач с `type="task"` автоматически получают неоновый цвет по умолчанию и отображаются как дедлайны. Их исходные данные остаются в `schedules.json`.

## Хранение данных

- `Application/Database/schedules.json` — пользовательские расписания и записи. Этот файл намеренно не включён в обновляющий архив: сохраните свою копию.
- `Application/Database/chats.json` — история чатов; создаётся автоматически и не включается в архив.
- `.env` — секрет API-ключа; не включается в архив.

## Агенты

- `TaskAgent` — операции с дедлайнами и чтение записей расписания.
- `PlannerAgent`, `ConflictAgent`, `ExplanationAgent` — пока заглушки для маршрута планирования.
- `OrchestratorAgent` — распознавание намерений и маршрутизация через LangGraph.
