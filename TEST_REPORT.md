## Результат

Все 30 автоматических тестов прошли успешно.

## Интерфейс TaskAgent

TaskAgent поддерживает следующие действия:

- `get` — получить задачу, событие или элементы расписания;
- `create` — создать задачу;
- `update` — изменить задачу;
- `delete` — удалить задачу.

Для чтения используется один универсальный метод `get`. Параметр `item_type` принимает `task`, `event` или `all`. Если `schedule_id` не указан при чтении коллекции, агент возвращает элементы всех расписаний.

Для выбора одного элемента используйте `task_id`, `event_id` или `item_id` вместе с `schedule_id`.

## Проверки

- получение задач и событий по типу;
- получение одного элемента по ID;
- получение элементов нескольких расписаний;
- фильтрация задач по приоритету и статусу;
- создание, изменение и удаление задач;
- защита событий при операциях с задачами;
- корректные сообщения при ошибочных аргументах;
- маршрутизация структурированных запросов через OrchestratorAgent;
- Flask API, главная страница, CSS и операции с расписаниями;
- расчёт расположения элементов таймлайна, включая элементы с неполным временем.
