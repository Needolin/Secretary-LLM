# Отчёт проверки: интерактивный таймлайн

## Реализованное взаимодействие

1. Отрезки и квадраты можно перетаскивать указателем между дорожками дней.
2. Время при переносе привязывается к ближайшей часовой отметке. Для интервала сохраняется продолжительность; если ближе к часу находится конец, привязывается конец, иначе — начало.
3. Перенос по вертикали меняет `day_index` и временные минуты в соответствии с целевым днём.
4. У элемента без времени горизонтальное перетаскивание назначает начало; вертикальное без смещения по горизонтали сохраняет его как элемент без времени.
5. После отпускания указателя клиент отправляет `PATCH /api/schedules/<schedule_id>/items/<item_id>`. При успехе страница загружается заново из JSON-базы, при ошибке отображается сообщение, затем восстанавливается отображение из базы.
6. Клик открывает компактное окно с названием, выбором дня, началом, концом, сохранением и удалением. Сохранение использует `PATCH`, удаление — `DELETE /api/schedules/<schedule_id>/items/<item_id>`.
7. В базе добавлены `update_item()` и `delete_item()`, которые по ID различают `event` и `task`, так что операция над одним типом не трогает другой.

## Ограничения проверки

Полные тесты Flask API запустить в текущей среде не удалось, потому что Flask не установлен, а установка зависимости требует недоступного сетевого доступа (`ModuleNotFoundError: No module named 'flask'`). Поэтому реальный HTTP-маршрут не был запущен здесь: для клиентского браузерного теста запросы API перехватывались тестовым обработчиком, а операции JSON-хранилища проверены отдельными unit-тестами. У себя перед запуском нужно установить зависимости из `requirements.txt` и выполнить `python -m unittest discover -s tests -v`.
