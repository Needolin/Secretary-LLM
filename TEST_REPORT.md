# Отчёт о проверке обновления Secretary-LLM

Дата: 8 ноября 2026 года.

## Результат

**49 автоматических тестов пройдены.** В тестовой среде также выполнены проверки синтаксиса изменённых Python-файлов, шаблона Jinja и трёх встроенных JavaScript-блоков.

## Запущенные тесты

```powershell
python -m unittest tests.test_task_agent tests.test_task_agent_hardening tests.test_timeline_layout tests.test_schedule_features tests.test_chat_database tests.test_ui_contract -v
```

Результат: 49 tests, OK.

Проверяются:

- CRUD записей расписания, фильтрация, ID и обработка некорректных данных;
- отсутствие потери событий при изменениях дедлайнов;
- фиксирование периода расписания после создания;
- закрепление и открепление расписаний;
- сохранение HEX-цветов событий и дедлайнов;
- отображение старых записей `type="task"` как дедлайнов;
- сохранение, переключение и удаление истории чатов;
- наличие правого контекстного меню расписаний, центрального таймлайна и правой панели чата;
- отсутствие переключателя периода после создания, блока недавних чатов и правой верхней иконки ассистента;
- расположение кнопки создания расписания над списком расписаний.

Дополнительные проверки:

- `py_compile` для `app.py`, обоих модулей базы данных, TaskAgent, OrchestratorAgent и `llm_config.py` — успешно;
- Jinja-шаблон `index.html` успешно отрендерен с тестовым контекстом;
- три встроенных JS-блока проверены через `node --check` — успешно.

## Что не проверено в этой среде

Полный запуск Flask test client и реальный вызов Cloud.ru из текущего окружения не выполнялись: необходимые зависимости Flask/LangGraph в нём не установлены, а установка пакетов недоступна. Поэтому 49 пройденных тестов не следует трактовать как подтверждение полного end-to-end браузерного сценария. После установки `requirements.txt` рекомендуется проверить приложение локально.

## Особенности совместимости данных

- `Application/Database/schedules.json` не входит в обновляющий архив: локальные расписания пользователя нужно сохранить.
- `Application/Database/chats.json` не входит в обновляющий архив: существующая история чатов остаётся на месте.
- `.env` не входит в архив: API-ключ Cloud.ru не перезаписывается и не публикуется.
- Старые записи с `type="task"` сохраняются и показываются в интерфейсе как дедлайны с неоновым крестиком.
- При первой загрузке старым расписаниям добавляется `pinned: false`, а старым записям без корректного цвета — цвет по умолчанию. Остальные поля записей не удаляются.

## Установка обновления

1. Остановить Flask через `Ctrl+C`.
2. Сделать копию папки проекта.
3. Распаковать обновляющий ZIP поверх текущей папки проекта с заменой файлов приложения.
4. Не удалять и не заменять `.env`, `Application/Database/schedules.json` и `Application/Database/chats.json`.
5. Выполнить `python -m pip install -r requirements.txt`.
6. Запустить `python Application/Site/app.py`.
